Physical table rehearsal

15–20 minutes · DM, flat TV, speakers, all five phones.

Status: not performed. This is a guide, not evidence of physical testing. Browser checks do not count as real devices.

In the app: Menu → Settings → Recovery & campaigns → Current status → Guided table rehearsal. Verify current files, open a practice copy, then name the observer and record the actual setup. The app records a separate result for each phone. Opening a practice copy releases existing phone joins; scan its QR. Do this when the group is ready, never during active play.

Save observations after each step. Note missing devices, hesitation, readability from every seat, and the precise control involved. Export notes when finished. A fix remains pending until a real retest passes. Return to the original campaign afterward and reconnect using its QR.

1. Get the real table ready

Use a practice copy. Put the TV flat at its real orientation, sit in the usual seats, connect speakers, and keep all five phones on the table Wi-Fi. Run table check. Record the display, browser and speaker setup.

Watch for: Does the DM know what the TV shows? Can everyone read the map and turn indicator from their own seat?
