VOICE STUDIO — CURRENT WORKFLOW — 11 October 2026

OPEN IT
Menu > Library > Voice studio, or Voice studio on an NPC card.
Voice profiles & setup opens the same cast/audition workflow. Back to Voice Studio
returns to recordings. Scene openings, published recaps, shared letters and
approved handouts still have their existing Prepare narration shortcuts.

EXISTING ELEVENLABS AUDITIONS
Choose Barthen, Sildar, Dracuseth or General narrator in Voice profiles & setup.
Expand Completed plugin auditions. Every voice remains proposed until explicitly
selected. Selecting a campaign voice is separate from approving a recorded line.

Plugin only means the report exists but the audio is not saved in this browser.
Open in ElevenLabs opens an external tab: its audio is NOT routed by this app.
Use headphones there. Download the existing sample, choose Save this audition
locally, and import that file in Voice Studio after confirming its exact script.
No generation is needed. The original plugin delivery settings were not reported.

Saved locally means the recording bytes and hash were verified. Open local
recording brings that take back to Studio. A missing/invalid file gets a recovery
message instead of an offline-ready claim. Local-service auditions also have
Copy cached audition to Voice Studio; this copies existing audio without generating
again and preserves mock labels. Imported copies do not select the voice or approve
public playback automatically.

RUN A LINE
1. Select a saved recording or prepare the exact approved audience text.
2. Save script, delivery and pronunciation changes. Old takes remain in history;
   changes mark them outdated instead of replacing the approved recording.
3. Import existing audio, or use a cached take. Choose separate private headphones.
4. Preview the whole take privately, then approve that take.
5. Play approved voice to table. The persistent strip says PRIVATE or TABLE and
   names the output. Narration volume is independent of background ducking.

Pause restores the previous background volume. Resume ducks it again. Skip stops
this line and may play the next queued approved recording. Stop voice clears audio
and TV subtitles immediately, including pending file loads. Mute / Stop sound also
interrupt narration. Opening narration alone does not switch the map, move tokens,
or reset combat. Show staged visual & ambience is a separate deliberate action.

Approve text, then Subtitles only / read aloud myself needs no recording/provider.
Subtitles show the whole passage, not timed word-by-word captions. Changed approved
recap events invalidate the linked recording and stop stale public narration.

NO NEW PROVIDER REQUESTS BY DEFAULT
Cached recordings remain usable when the service or internet is unavailable.
Create mock take is available only in a practice campaign: it saves synthetic
silence, not speech. Mock recordings cannot be approved for the live campaign.
Real generation requires a new allowance saved in Voice profiles & setup; old
service settings do not count as new approval in the current app session. Backend
credit caps still apply. Account keys, billing settings and output choices are
outside campaign exports. No new real provider requests were made for this update.

BACKUP & RESTORE
Use the normal full campaign backup. It embeds the locally imported recordings,
older takes, hashes, approvals and plugin generation references. Restore into a
new campaign/profile and select audio outputs again. Device names are not exported.
Replay uses the saved bytes and needs no new speech generation. Plugin-only links
are not an offline audio backup; import their files first. Missing files should be
restored or imported from an existing saved copy, not regenerated automatically.

PHYSICAL OUTPUTS
Private preview requires named headphones physically separate from table speakers
and the computer default output. Unsupported or uncertain routing blocks preview.
Device changes stop playback; previews never fall back to speakers. The app cannot
prove where sound is physically heard from a simulated browser check. Headphone /
speaker separation, volume and intelligibility remain physical checks, not claims
from the automated rehearsal. Manual reading and subtitles remain available.
