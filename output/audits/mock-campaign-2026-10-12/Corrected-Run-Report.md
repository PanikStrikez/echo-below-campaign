## Problems found

1. **Recovery growth:** large repeated restore points exhausted the disposable browser's storage. Creation failed safely, but the explanation was hard to find. Add visible storage usage and restore-point retention controls.
2. **Source connectivity:** the pool-room card omitted a dry northern passage present on the source map. Link each room's exits to verified geometry.
3. **Map accuracy:** some painted maps remain illustrative rather than source-calibrated. Use the verified tactical layout for movement and clearly label illustrative art.
4. **Higher-level actions:** Sneak Attack compilation and descriptions retained 2d6 after further advancement. A mock-only adjustment allowed this rehearsal; production needs level-aware compilation and card text together.
5. **Turn reminders:** effects on defeated targets could still block End turn. Resolve irrelevant reminders automatically or provide a prominent reviewed dismissal.
6. **Phone screenshots:** API packets were current while rendered pages retained older data. Reloading simulated clients corrected final captures. Add a capture/render revision check; never call a screenshot current merely because the API is fresh.
7. **Objective continuity:** the phone objective still asked to find Nundro after rescue. The closing objective was explicitly corrected in the practice campaign; connect reviewed outcomes to objective proposals.
8. **Inventory clarity:** ammunition resource counts and equipment quantities can diverge. Show one authoritative carried quantity.
9. **Spell completeness:** new spell names can exist as references without structured resolution. Keep a visible reference-only status and DM ruling path.
10. **Feedback wording:** an effect-only save could show zero healing. Use effect-specific language.

- Independent browser checks for token dragging, reviewed combat, undo, initiative, reaction boundaries and session-map navigation passed earlier; these are narrower than a complete campaign certification.
- Several combat-driver errors required corrections: multiattack, stale state pointers after atomic commits, missed NPC Shield, retreat handling, and a failed negotiation initially misclassified. Superseded results are retained as audit evidence. These are harness mistakes, not demonstrated product defects.
- Exact movement, sight lines, cover, all monster traits and every unusual spell were not rigorously validated by this narrative harness. Do not treat the run as proof of complete mechanical correctness or encounter balance.
- No physical TV/phones/speakers tested; no real voice/provider requests; live campaign untouched. Optional unplayed branches remain untested.
