What changed

  • DM dependencies download in parallel while executing in the same order. Private dependencies are excluded from player pages.
  • Unchanged TV updates reuse the current map: 12 unnecessary map rebuilds before, zero after. Changed positions, views and layers still update.
  • Position-only changes retain the roster. Its controls follow the latest token after commands and undo.
  • Combat and pending-request phone updates poll at 450 ms; quiet exploration and offline retries stay at 950 ms.
  • Search avoids repeated scoring and token scans; result identities stayed identical.

Smaller public map sections

The original Phandalin image is 1536 × 1024 pixels (4.10 MB). Four optional 768 × 512 crops each use about 1.12 MB. Every saved pixel was compared with the source, including the shared boundaries. One section decoded in a median 5.3 ms versus 14.9 ms for the full image. These are exact crops, not new detail. They are prepared assets only; the current atlas and saved geometry are unchanged.

Limits

  • Single paired run; timings vary with machine load. Samples are not a statistical guarantee.
  • Real headless Chrome and temporary real HTTP services on loopback; no physical TV, Wi-Fi, phone or speaker claim.
  • Scene-map loading was slower in the measured after run. Effects remained near the headless animation-frame cap; no proven effects gain.
  • Drag-to-frame includes mouse automation. It is not a direct hardware input-latency measurement.
  • Optional map crops preserve exact pixels but are not wired into automatic scene navigation. All four together use more disk space.
  • Modules still execute in original order. Downloads are preloaded in parallel; feature modules are not lazy-loaded.
