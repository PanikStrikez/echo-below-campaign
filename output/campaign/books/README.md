# Local rulebook shelf

The table opens five privately supplied rulebooks through local links: the
2014 Player's Handbook, Dungeon Master's Guide, and Monster Manual, plus
Xanathar's Guide to Everything and Tasha's Cauldron of Everything. The first
two links point to the project source mirror; the other three point to Ethan's
Downloads folder. The PDF files are not copied into this app. If a file moves,
choose it again in **Rules & books**. The selected
file remains available until the page is refreshed.

The shelf also links the private Lost Mine of Phandelver and Dungeon of the Mad
Mage PDFs in the project source mirror. Lost Mine is an image scan with a
visually checked index for the Cragmaw opening, Phandalin, and Redbrand rooms.
The remaining rooms are chapter-linked until their exact pages are checked.
Dungeon of the Mad Mage has a text layer; its printed-to-PDF offset is +1.

The **Story** drawer includes expandable marked DM map previews for Cragmaw
Hideout, Phandalin, Redbrand Hideout, Thundertree, Cragmaw Castle, Wave Echo
Cave, and the first three Undermountain floors. These page images are stored
under `private-maps/` and are for the local DM interface. They contain keyed
numbers and other spoilers. They are not selected as player battle maps or
sent in the player display payload.

The Lost Mine scan does not contain a searchable text layer. Its hand-checked
index covers the opening, town, Redbrand Hideout, and adventure creature
appendix. The rest of Lost Mine still needs page-by-page indexing. The Mad
Mage chapter and appendix page links are confirmed against its text layer,
but a full room-by-room index has not been built. The source shelf keeps
chapter links available in the meantime.

`srd-5.1-cc.pdf` is the 2014 rules System Reference Document 5.1. Its license
and attribution are in `SRD-LICENSE.txt`. The generated rules index contains
catalog metadata and word-to-page search links, not copied text from the
privately supplied handbooks.

For a version shared with other people, remove the local PDF links, the
private-book OCR page index, and the private campaign references. Keep the
attributed SRD file and its entry links, or link to the official SRD. Review
any custom adventure text, art, and character files separately before sharing.

The scanned Player's Handbook is missing some pages relative to the printed
book. Its PDF page links are exact; printed-to-PDF page offsets are confirmed
for the main chapter anchors and commonly used rules. An unconfirmed offset
is labeled as approximate in the viewer.
